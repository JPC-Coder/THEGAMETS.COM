GAMETS FIRST SERIES IMAGE FILES

Place each finished card-front image in this folder using this exact convention:

card-01-front.webp
card-02-front.webp
card-03-front.webp
...
card-50-front.webp

The website also accepts .png or .jpg if you update the `frontImage` value for
that card in app/page.tsx (and assets/js/app.js in the downloadable static copy).

All card backs use this shared file:
JPC 2026 BACK CARD LOGO.jpg

The official orange-and-blue JPC Creative Studios artwork is installed.

Recommended dimensions: 1200 x 1680 pixels (5:7 portrait ratio).
Recommended format: WebP, quality 82-88, under 500 KB per image.

The current website package contains optimized WebP artwork for the complete
First Series: cards 01 through 50.
